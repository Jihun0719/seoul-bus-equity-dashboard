# 전처리 데이터 설명

## 파일별 용도

| 파일 | 용도 |
|---|---|
| `bus_stops.csv` | 정류장별 위치와 소속 자치구 |
| `districts.geojson` | 자치구별 생활인구·정류장 수·면적과 지도 경계 |
| `validation_report.json` | 생활인구 기준 날짜와 데이터 정제·제외 내역 |

## bus_stops.csv

한 행은 하나의 정류장입니다. 인코딩은 UTF-8 BOM(`utf-8-sig`), 좌표계는 WGS84 경위도(EPSG:4326)입니다.

| 열 이름 | 자료형 | 의미 | 단위·형식 |
|---|---|---|---|
| `stop_id` | 문자열 | 원본 `노드 ID`에서 가져온 정류장 식별자 | 앞자리 0 유지 |
| `stop_name` | 문자열 | 정류장 이름 | — |
| `longitude` | 실수 | 경도(X) | 도 |
| `latitude` | 실수 | 위도(Y) | 도 |
| `district_code` | 문자열 | 소속 자치구 코드 | 코드 문자열 |
| `district_name` | 문자열 | 소속 자치구 이름 | — |

## districts.geojson

한 행은 하나의 자치구입니다. 경계는 WGS84 경위도이며 파일에는 CRS84(경도, 위도 순서)로 표기됩니다.

| 열 이름 | 자료형 | 의미 | 단위·형식 |
|---|---|---|---|
| `district_code` | 문자열 | 자치구 코드; 정류장 표와 연결하는 기준 | 코드 문자열 |
| `district_name` | 문자열 | 자치구 이름 | — |
| `geometry` | 공간 도형 | 자치구 경계 | 경위도 좌표 |
| `area_km2` | 실수 | 투영 좌표계에서 계산한 자치구 면적 | km² |
| `living_population` | 실수 | 해당 날짜의 총생활인구수; 주민등록인구와 다름 | 명 |
| `population_date` | 문자열 | 생활인구 기준 날짜; 정류장·경계의 기준 날짜가 아님 | YYYYMMDD |
| `bus_stop_count` | 정수 | 자치구에 배정된 정류장 수; 노선 수·운행 횟수가 아님 | 개 |

## validation_report.json

표 형태가 아닌 JSON 객체이며, 아래 항목에 처리 기록이 들어 있습니다.

| 항목 | 자료형 | 의미·단위 |
|---|---|---|
| `raw_rows` | 객체 | 원본 정류장·생활인구·자치구 행 수(정수, 행) |
| `district_crs` | 문자열 | 원본 자치구 경계의 좌표계 |
| `bus_stops` | 객체 | 제외 유형·잘못된 행·중복 행 수와 정제 후 행 수(정수, 행) |
| `population` | 객체 | `date`: 생활인구 기준 날짜(문자열, YYYYMMDD), `rows`: 행 수(정수) |
| `districts` | 객체 | 경계 행 수(정수), 좌표계(문자열), 수정 도형 수(정수, 개) |
| `merge` | 객체 | 배정·미배정·복수 배정 정류장 수(정수, 개)와 제외 ID 목록(문자열 배열) |

보고서의 경계 좌표계는 원본·정제 단계 기준이며, 최종 GeoJSON의 좌표계와 다를 수 있습니다.

## 정제·제외 기준

- 버스 정류장이 아닌 한강선착장을 제외합니다.
- 정류장 ID가 결측이거나 좌표가 결측·숫자로 변환 불가·허용 범위 밖인 행을 제외합니다. 허용 범위는 경도 -180~180도, 위도 -90~90도입니다.
- 정제에 사용하는 열이 모두 같은 중복 행은 하나만 남깁니다. 같은 정류장 ID에 서로 다른 정보가 있으면 오류로 중단합니다.
- 정확히 하나의 자치구와 겹치는 정류장만 포함합니다. 미배정·복수 배정 정류장은 제외하고 ID를 보고서에 기록합니다.
- 생활인구는 선택한 날짜만 사용하고 서울 전체 합계(`11000`)를 제외합니다. 완전 중복 행은 제거합니다.
- 생활인구가 결측이거나 0 이하인 경우, 자치구 코드가 중복되거나 경계 코드와 다른 경우, 자치구가 25개가 아닌 경우에는 오류로 중단합니다.
- 자치구 경계의 좌표계 정보를 확인하고 유효하지 않은 도형은 수정합니다. 병합 후 면적이 양수인지, 구별 정류장 수 합계가 최종 정류장 수와 일치하는지 확인합니다.
